LuxStay: reservas de hoteles con Docker

  • Docker Compose
  • Flask (Python)
  • MySQL
  • Nginx

Aplicación web de reserva de hoteles desplegada con Docker Compose en tres contenedores: una base de datos MySQL, la aplicación en Flask y Nginx como proxy inverso. Permite buscar por ciudad y fechas, ver la ficha de cada hotel y confirmar la reserva.

La base de datos incluye un procedimiento almacenado que comprueba la disponibilidad antes de guardar la reserva y un trigger que registra una auditoría de cada reserva.

Para probarlo: descomprimir, abrir una terminal en la carpeta y ejecutar docker compose up --build. Se abre en http://localhost.
